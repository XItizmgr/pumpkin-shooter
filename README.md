# pumpkin Shooter
Pumpkin Shooter is a small shooting game where u have to shoot coming  pumpkin and dodge it's bullet as u shoot. The longer u stay alive the more enemy(pumpkin ) will spawn and shoot u . HEHEHE try to survive more then 3 level.(challange)

## About the game

Pumkine shooter is a mini python game made using python's pyame library. Where u control a ghost using ur ASDW key  and shoot pumpkin that are falling and shooting u as well and in that situiation u have to survive u will get 3 lives and 100 hp.

10 hp will deduct every time u get shoot by pumpkin after loosing all 100 hp u will lose.

if any of the pumpkin touch the bottom then u will lose ur live after ur lives reach 0 u will lose the game

## How to play 
U can use Arrow key Or AWSD to move and space to shoot
- A 0r left arrow key  to got left 
- D 0r Right arrow key  to got Right 
- W 0r Up arrow key  to got Up
- S 0r Down arrow key  to got Down 
- space to shoot ur bullet
